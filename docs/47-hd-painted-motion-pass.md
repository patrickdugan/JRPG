# High-detail character motion: source recovery and paint-quality gate

The art director rejected the procedural 144×160 SVG character study as unsuitable for final presentation. The next character-animation lane is detailed, concept-quality painted character motion with precise source provenance, stable identity, real transparent exports and isolated attack effects.

## Existing work

The canonical July 2026 high-resolution illustration sources for Nikola Dražanić, Father Mateus Avelar and Shogun Kurozane remain in `assets/art/concepts/`; July face boards for Ren Ishikawa, Aya Shinohara, Genta Mononobe, Kiku Nawa and Miyo Senda remain in `assets/art/party-portrait-suite-v2/sources/`.

An HD draft package named `JRPG_Canonical_Art_and_HD_Animation_v2.zip` was produced in this ChatGPT work session. It contains:
- three six-pose painted PNG animation sheets and **18 separate transparent painted key frames** for Nikola, Mateus and Kurozane;
- original unmodified full-body art and source sheets;
- isolated character-body crops and separate detached effect fragments to prevent adjacent cel bleed;
- original July face references for the remaining five playable characters, organized as **40 expression crops**;
- SHA-256 manifests, native-size frame dimensions, two offline review galleries and an import helper.

The image binaries are distributed in the conversation's downloadable archive. **They have not been checked into this GitHub branch.** The branch's GitHub Actions workflow exports original canonical repository references to a review artifact.

## Canonical playable identities

Ren Ishikawa, Aya Shinohara, Nikola Dražanić, Father Mateus Avelar, Genta Mononobe, Kiku Nawa, and Miyo Senda. Use each character's established Japanese or European period identity, face, garment construction, and characteristic equipment. Generic overview posters from the image-production experiments included invented characters and must not become sprite authority.

## Art-production acceptance

- Original images are **painted PNG sources**, not native editable SVG vectors. The previous low-detail procedural SVG suite remains a separate technical animation study.
- Keep the current tested pixel-art runtime active until new art has passed native-size contact review, intact head/body anatomy, common ground anchors, compatible attack telegraphs, controlled independent VFX, GPU/CPU profiling and an end-to-end browser playthrough.
- The 18 HD poses are key illustrations. The remaining five party members still require their HD combat sheets, and all characters need coherent in-between animation before replacement in game.
- Source imports must verify SHA-256, canonical IDs and pose dimensions. Edits belong to a review candidate folder with explicit opt-in in the game, and must never rewrite campaign progress.
