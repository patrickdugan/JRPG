# JRPG Roster Keystone

The 62-identity production index is maintained at [`assets/art/roster-keystone/README.md`](assets/art/roster-keystone/README.md), backed by [`roster.json`](assets/art/roster-keystone/roster.json). It tracks canonical IDs, existing pixel animation, painted six-pose sources, 24-frame motion, Git availability, engine integration and human visual review. Missing enemies are generated in source-derived animation batches with distinct provenance.
