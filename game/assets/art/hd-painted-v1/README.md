# Optional HD Painted Artwork

Use the importer in \`game/tools/install-hd-painted-art.py\` to copy the
SHA-256 verified 12 rendered six-pose PNG sheets and manifest from
the art-pack ZIP into this folder. The game engine has a safe classic
fallback when files have not been installed.

Enable the preview with \`art=hd\` in the Action Campaign battle URL.
The art is generated painted raster key poses, not editable SVG or
full-motion production animation. Kurozane's six transformation
studies are excluded from automatic attack animation.
