# Bells of the Black Chrysanthemum

An original, gothic historical-fantasy action JRPG set in a fictionalized early Edo Japan, where a vampiric Shogun turns persecution into a supernatural order. It combines top-down party exploration with side-view real-time combat, free movement, committed attack animations, post-animation cooldowns, and readable elemental detail.

## Scope guardrails

- Chapter-based town / route / dungeon JRPG progression in the 16-bit console tradition.
- Not a metroidvania: no ability-gated backtracking loop or open-ended castle crawl is required for the core game.
- Side-view real-time battle: free movement, jump, wind-up, one active hit, animation recovery, post-animation cooldown, defense, and elemental matchup matter.
- All characters, art, and lore are original. The European apostate priest is an original fictional character rather than an actor likeness or a film adaptation.
