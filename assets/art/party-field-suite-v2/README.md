# Party field suite v2

This is the production-quality top-down party atlas for the seven playable field leaders. It is authored from native-resolution code primitives and canonical character palettes. The side-view combat atlas is used only as a visual quality and identity reference; no side-view raster pixels are sampled or transformed.

## Runtime contract

- Seven rows: Ren, Aya, Nikola (`lise` compatibility key), Mateus, Genta, Kiku, and Miyo.
- Twenty-two columns: four directional idles, four-phase directional walks, south interact, and south hurt.
- Native frame: 40 × 56 RGBA with binary alpha.
- Pivot and foot point: `(20, 52)`.
- Walk phases: contact, compression, passing, extension at 80 ms each.
- Runtime movement owns root motion; the atlas only supplies pose animation.

## Files

- `party-field-suite-v2.source.json`: editable identity, geometry, timing, and quality contract.
- `build_party_field_suite_v2.py`: deterministic native-resolution builder and validator.
- `party-field-atlas-v2.png`: transparent runtime atlas.
- `party-field-contact-sheet-v2.png`: labeled review sheet.
- `party-field-motion-preview-v2.gif`: nearest-neighbor four-direction motion review.
- `manifest.json`: frame rectangles, phases, pivots, bounds, palette counts, hashes, and provenance.

Run `python build_party_field_suite_v2.py` to rebuild. Run `python build_party_field_suite_v2.py --check` to prove every generated byte matches the checked-in outputs.

The previous 32 × 48 foundation remains available as a compatibility artifact. The browser runtime uses this v2 atlas.
